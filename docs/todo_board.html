协作规则

提出功能点时尽量写明背景和目标，便于其他参与者判断价值与工作量。认领后应填写自己的名字，并在推进时主动更新状态。

如果某个功能点遇到外部依赖、接口权限或设计不明确，可标记为“阻塞”，让其他人看到卡点在哪里。

页面会把所有数据保存在当前浏览器的本地存储中，适合小组内部共享模板后各自维护。

当前页面文件是静态 HTML。直接双击打开，或运行 python -m http.server 后在浏览器访问，都可以使用。
